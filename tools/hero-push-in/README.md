# Наезд камеры в экран монитора

Собирает `assets/hero/screen-push-in.mp4` (2560×1440, 24 к/с, 4 с): камера от последнего кадра
ролика «улица → офис» подъезжает к монитору, пока в кадре не остаётся только секция Agents.

Картинка на мониторе — не генерация, а настоящий рендер сайта (`shot.mjs`), натянутый на экран
по перспективе, поэтому текст остаётся чётким, а последний кадр совпадает с секцией Agents.
Человек и кресло вынесены в отдельный слой (маска — Higgsfield background remover + ручные контуры
в `masks.py`) и уходят из кадра быстрее фона — это даёт параллакс. Фон за ними дорисован в `masks.py`.

Запуск (в рабочей папке, где лежат `../last.png` — последний кадр ролика — и `alpha_full.png` — маска из remover):

```sh
node shot.mjs 1.7777777777777777 tex.png   # UI 2560×1440
python3 masks.py                            # fg.png и plate.png
python3 render.py video screen-push-in.mp4
```

Углы экрана на последнем кадре — `QUAD` в `geom.py`; длительность и easing — в начале `render.py`.
