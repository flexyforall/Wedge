# hero/ — первый экран и видео по скроллу

Первый экран закреплён, пока пользователь прокручивает страницу: скролл проматывает видео кадр за кадром
(здание → офис → экран), а последний кадр — это ровно секция Agents, которая затем плавно её подменяет.
Текст первого экрана исчезает за первые 10 % прокрутки; дальше при прокрутке вверх сверху выезжает компактный хедер
(при прокрутке вниз он прячется). На офисной сцене (≈ 6,2–7,3 с видео) прокрутка идёт медленнее, и поверх кадра
появляется «One outcome. Many agents.» (Figma «second», `1057:21749`); шкала справа внизу показывает, сколько видео
пройдено. Видео доходит до последнего кадра ровно там, где начинается живая секция Agents, — «картинки интерфейса», которая
не реагирует на клики, нет. А если остановить прокрутку на финальном наезде камеры (последние ~8 %), страница сама
докрутит до секции Agents (или обратно вверх, если крутили вверх). Тайминги — `TIME_KEYS`, `CHAPTER` и `SNAP_FROM`
в `js/main.js`: если поменяется ролик, их нужно подогнать под новые сцены.

## Как заменить видео

Последний кадр нового ролика должен совпадать с секцией Agents при ширине 1440 px (кадр 16:9).
Из нового исходника нужно заново собрать `hero-scrub.mp4` и `hero-poster.jpg`:

```sh
ffmpeg -i new-video.mp4 -an -vf "scale=2880:-2:flags=lanczos" -c:v libx264 -preset slow -crf 23 \
  -g 6 -keyint_min 6 -sc_threshold 0 -bf 0 -pix_fmt yuv420p -movflags +faststart hero-scrub.mp4
ffmpeg -i new-video.mp4 -frames:v 1 -q:v 3 hero-poster.jpg
```

Частые ключевые кадры (`-g 6`) обязательны: без них прокрутка назад и быстрые рывки скролла будут подтормаживать.
